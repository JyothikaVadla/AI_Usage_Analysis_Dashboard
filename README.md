# AI_Usage_Analysis_Dashboard
The **AI Usage Analytics Dashboard** is an interactive data analytics project developed using **Excel, MySQL, SQL, and Power BI**. The dashboard analyzes user behavior and AI-tool usage patterns to understand:
- 👥 User distribution
- 🤖 AI tool adoption and usage
- ⏱️ AI usage hours
- 💳 Subscription plan distribution
- 🌍 City-level usage
- 👨‍💼 Profession-level usage
- 📈 Usage trends over time

The project converts raw user and usage data into meaningful visual insights through an interactive Power BI dashboard.
